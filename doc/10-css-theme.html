Aufgabe 10

CSS-Techniken & Theme

🎯 Lernziel

Du optimierst das visuelle Erscheinungsbild der Anwendung. Du lernst Blazors Scoped CSS (CSS Isolation), den ::deep-Pseudo-Selektor, die Implementierung eines Dark/Light-Mode-Wechsels und responsive Breakpoints.

🔧 Konzepte

.razor.css (Scoped CSS) ::deep data-bs-theme CSS-Variablen (custom properties) @media (prefers-color-scheme) @media (max-width) JSInterop für localStorage

📋 Aufgabe

  1. 1. Erstelle für jede deiner Komponenten eine Scoped CSS-Datei (Komponente.razor.css). Verschiebe komponenten-spezifische Styles aus globalem CSS dorthin.
  2. 2. Nutze ::deep in einer Parent-Komponente, um das Styling einer Child-Komponente zu beeinflussen (z.B. alle Tabellen in einer Card einheitlich formatieren).
  3. 3. Implementiere einen Dark/Light-Mode-Button:
    • Ein Button in der Seitenleiste ruft per IJSRuntime.InvokeVoidAsync("toggleTheme") eine JS-Funktion auf.
    • Die JS-Funktion setzt data-bs-theme="dark" aufs <html>-Element und speichert die Präferenz in localStorage.
  4. 4. Ergänze benutzerdefinierte CSS-Variablen für Dark Mode (z.B. andere Sidebar-Hintergrundfarbe, andere Card-Schatten).
  5. 5. Mache die Sidebar responsiv: Unter 640px Breite wird sie zu einem Hamburger-Menü, das sich über den Content legt.
  6. 6. Bonus: Füge prefers-color-scheme als Standard hinzu, damit der Dark Mode automatisch der Betriebssystem-Einstellung folgt.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Scoped CSS (NavMenu.razor.css):
::deep .nav-link {
    color: var(--text-muted);
    padding: 8px 16px;
    border-radius: 6px;
    transition: all 0.15s;
}

::deep .nav-link.active {
    color: var(--accent);
    background: var(--accent-light);
}

// CSS-Variablen für Dark Mode:
:root {
    --sidebar-bg: #f8f9fa;
    --card-shadow: 0 1px 3px rgba(0,0,0,0.12);
}

[data-bs-theme="dark"] {
    --sidebar-bg: #212529;
    --card-shadow: 0 1px 3px rgba(0,0,0,0.4);
}

// JS-Interop für Theme-Toggle (wwwroot/js/theme.js):
window.toggleTheme = function () {
    var html = document.documentElement;
    var current = html.getAttribute('data-bs-theme') || 'light';
    var next = current === 'dark' ? 'light' : 'dark';
    html.setAttribute('data-bs-theme', next);
    localStorage.setItem('theme', next);
};

window.applyTheme = function () {
    var saved = localStorage.getItem('theme');
    if (saved) {
        document.documentElement.setAttribute('data-bs-theme', saved);
    } else if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
        document.documentElement.setAttribute('data-bs-theme', 'dark');
    }
};

// Blazor-Seite ruft JS auf:
@inject IJSRuntime JS

<button @onclick="ToggleTheme">🌓 Theme</button>

@code {
    private async Task ToggleTheme()
    {
        await JS.InvokeVoidAsync("toggleTheme");
    }
}

// wwwroot/js/theme.js
window.toggleTheme = function () {
    const html = document.documentElement;
    const current = html.getAttribute('data-bs-theme') || 'light';
    const next = current === 'dark' ? 'light' : 'dark';
    html.setAttribute('data-bs-theme', next);
    localStorage.setItem('theme', next);
};

window.applyTheme = function () {
    const saved = localStorage.getItem('theme');
    if (saved) {
        document.documentElement.setAttribute('data-bs-theme', saved);
    } else if (window.matchMedia('(prefers-color-scheme: dark)').matches) {
        document.documentElement.setAttribute('data-bs-theme', 'dark');
    }
};

window.addEventListener('DOMContentLoaded', window.applyTheme);
// NavMenu.razor (Auszug)
@inject IJSRuntime JS

<nav class="flex-column">
    <div class="d-md-none text-end p-2">
        <button class="btn btn-sm btn-outline-secondary"
                @onclick="ToggleNav">
            ☰
        </button>
    </div>

    <div class="@(navOpen ? "d-block" : "d-none d-md-block")">
        <NavLink class="nav-link" href="" Match="NavLinkMatch.All">
            🏠 Home
        </NavLink>
        <NavLink class="nav-link" href="calculator">
            📊 Calculator
        </NavLink>

        <button class="btn btn-sm btn-outline-secondary mt-2 w-100"
                @onclick="ToggleTheme">
            🌓 @(isDark ? "Dark" : "Light") Mode
        </button>
    </div>
</nav>

@code {
    [Inject] private IJSRuntime JS { get; set; } = null!;
    private bool isDark;
    private bool navOpen;

    protected override async Task OnAfterRenderAsync(bool firstRender)
    {
        if (firstRender)
        {
            var saved = await JS.InvokeAsync<string>("localStorage.getItem", "theme");
            isDark = saved == "dark";
        }
    }

    private async Task ToggleTheme()
    {
        await JS.InvokeVoidAsync("toggleTheme");
        isDark = !isDark;
    }

    private void ToggleNav()
    {
        navOpen = !navOpen;
    }
}

💡 Tipps

  • Scoped CSS-Dateien heißen genau wie die .razor-Datei, mit angehängtem .css (z.B. NavMenu.razor.css).
  • ::deep ist Blazors Äquivalent zu "durchreichenden" Styles. Syntax: ::deep .meine-klasse { ... }.
  • Bootstrap 5.3+ unterstützt data-bs-theme="dark" nativ. Kein separater Dark-Mode-CSS mehr nötig – nur eigene Overrides.
  • CSS-Variablen im :root-Selektor definieren, im Dark Mode mittels [data-bs-theme="dark"] überschreiben.
  • Responsive Breakpoints immer mobil zuerst denken: @media (min-width: 641px) für Desktop-Regeln.

✅ Akzeptanzkriterien

  • Jede Komponente hat eine eigene Scoped CSS-Datei
  • ::deep wird an mindestens einer Stelle verwendet
  • Dark/Light Mode kann per Button umgeschaltet werden
  • Die Präferenz bleibt nach Seitenneuladung erhalten (localStorage)
  • Sidebar ist unter 640px mobil nutzbar (Hamburger + Overlay)
  • CSS-Variablen für konsistente Farben im Dark Mode
