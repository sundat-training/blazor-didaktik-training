Aufgabe 01b

Select mit @bind

🎯 Lernziel

Du löst dieselbe Aufgabe wie in 01a, aber mit @bind und @bind:after – dem Blazor-Weg für bidirektionale Bindung mit anschließender Aktion. Du siehst, wie viel Boilerplate durch @bind eingespart wird.

🔧 Konzepte

<select> <option> @bind @bind:after foreach EventCallback<T>

📋 Aufgabe

  1. 1. Erstelle eine neue Blazor-Komponente CategorySelector.razor.
  2. 2. Definiere ein festes Array von Kategorien als Komponenten-Feld (z.B. "Ordinary", "Compressed", "Moon", "Compressed Moon").
  3. 3. Baue ein <select> mit @bind="selectedCategory".
  4. 4. Zeige die gewählte Kategorie unterhalb des Dropdowns an.
  5. 5. Gib die Auswahl per EventCallback<string> nach oben an die Parent-Komponente weiter – nutze @bind:after.

📌 Der Unterschied zu 01a

In 01a hast du @onchange + value manuell gesetzt und ChangeEventArgs selbst ausgewertet. Hier übernimmt @bind das Setzen von value und das Auslesen des neuen Werts – du brauchst nur noch @bind:after für die Parent-Benachrichtigung.

💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine für diese Aufgabe:

// @bind + @bind:after mit Inline-Lambda:
[Parameter]
public EventCallback<string> OnCategoryChanged { get; set; }

<select @bind="selectedCategory"
        @bind:after="() => OnCategoryChanged.InvokeAsync(selectedCategory)">
    <option value="" disabled>Bitte wählen...</option>
    @foreach (var cat in categories)
    {
        <option value="@cat">@cat</option>
    }
</select>

@code {
    private string selectedCategory = "";
    private string[] categories = { "Ordinary", "Compressed", "Moon", "Compressed Moon" };
}

💡 @bind aktualisiert selectedCategory automatisch. @bind:after wird nach jeder Aktualisierung aufgerufen – das Lambda ruft direkt den EventCallback auf.

💡 Kein ChangeEventArgs, keine extra Methode, kein manuelles value= – maximale Reduktion.

🔧 Teil-Lösung – Code-Gerüst

Properties und Methoden-Signaturen – ergänze die fehlenden Teile (markiert mit ❌):

@* CategorySelector.razor *@

<label>@Title</label>
<select @bind="selectedCategory" ❌>
    <option value="" disabled>Bitte wählen...</option>
    @foreach (var cat in categories)
    {
        <option value="@cat">@cat</option>
    }
</select>

@if (!string.IsNullOrEmpty(selectedCategory))
{
    <p>Gewählt: <strong>@selectedCategory</strong></p>
}

@code {
    [Parameter]
    public string Title { get; set; } = "Kategorie wählen";

    [Parameter]
    public EventCallback<string> OnCategoryChanged { get; set; }

    private string selectedCategory = "";
    private string[] categories = { "Ordinary", "Compressed", "Moon", "Compressed Moon" };
}

📌 Fehlender Teil: @bind:after="() => OnCategoryChanged.InvokeAsync(selectedCategory)" im <select>. Das Lambda feuert den Callback nach jeder Bindungs-Aktualisierung – keine extra Methode nötig.

🏁 Vollständige Lösung 
@* CategorySelector.razor *@

<div class="mb-3">
    <label class="form-label fw-bold">@Title</label>
    <select class="form-select" @bind="selectedCategory"
            @bind:after="() => OnCategoryChanged.InvokeAsync(selectedCategory)">
        <option value="" disabled selected>Bitte wählen...</option>
        @foreach (var cat in categories)
        {
            <option value="@cat">@cat</option>
        }
    </select>

    @if (!string.IsNullOrEmpty(selectedCategory))
    {
        <div class="mt-2 p-2 bg-light rounded border">
            Gewählt: <strong>@selectedCategory</strong>
        </div>
    }
</div>

@code {
    [Parameter]
    public string Title { get; set; } = "Kategorie wählen";

    [Parameter]
    public EventCallback<string> OnCategoryChanged { get; set; }

    private string selectedCategory = "";
    private string[] categories = { "Ordinary", "Compressed", "Moon", "Compressed Moon" };
}

Verwendung in einer Parent-Seite:

<CategorySelector Title="Erz-Kategorie"
                  OnCategoryChanged="@((string cat) => Console.WriteLine(cat))" />

💡 Tipps

  • @bind ist ab .NET 8 verfügbar und ersetzt das manuelle value + @onchange.
  • Mit @bind:after hängst du ein Inline-Lambda an – keine extra Methode nötig.
  • Vergleiche die Code-Menge mit Aufgabe 01a – @bind spart dir ChangeEventArgs, manuelle Zuweisung und eine separate Methode.
  • Der Callback wird bei jeder Auswahl gefeuert, auch bei leerem Platzhalter. Wer das unterdrücken will, packt ein if ins Lambda.

✅ Akzeptanzkriterien

  • Dropdown zeigt alle Kategorien als Optionen an
  • Platzhalter "Bitte wählen..." ist vorausgewählt
  • Die gewählte Kategorie wird unterhalb des Dropdowns angezeigt
  • Die Auswahl wird per EventCallback an die Parent-Komponente gemeldet
  • Der Callback feuert bei jeder Auswahl – inklusive Platzhalter. Wer das unterdrücken will, ergänzt ein if im Lambda.
  • Es wird @bind und @bind:after verwendet – kein manuelles @onchange
