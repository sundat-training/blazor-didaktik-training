Aufgabe 09

Component State & Kommunikation

🎯 Lernziel

Du kombinierst alle bisherigen Komponenten zu einer funktionsfähigen Seite. Du lernst das "Controller"-Pattern: Eine Parent-Komponente hält den gesamten State und verteilt ihn per [Parameter] an Child-Komponenten. Änderungen in den Kindern werden per EventCallback zurückgemeldet.

🔧 Konzepte

[Parameter] EventCallback<T> Parent→Child Datenfluss Controller-Komponente State orchestrieren @if / Loading / Error

📋 Aufgabe

  1. 1. Erstelle eine Seite Calculator.razor – sie ist der "Controller". Sie hält: selectedItem, quantity, fee, result, isLoading, errorMessage.
  2. 2. Baue die Komponenten aus den vorherigen Aufgaben in die Seite ein:
    • Ein gekaskadetes Select (Aufgabe 02) für Kategorie + Item
    • Ein QuantityInput (Aufgabe 03) für die Menge
    • Ein DualInput (Aufgabe 04) für die Gebühr
    • Eine Tabelle (Aufgabe 05/06) für Ergebnisse
  3. 3. Verdrahte die EventCallbacks der Kinder mit Handler-Methoden in Calculator.razor.
  4. 4. Wenn Item, Menge und Gebühr gültig sind, berechne (oder rufe API auf) und setze result.
  5. 5. Zeige während der Berechnung einen Spinner (isLoading). Bei Fehler eine rote Meldung (errorMessage).
  6. 6. Der "Berechnen"-Button ist deaktiviert, solange nicht alle Eingaben gültig sind.
  7. 7. Sorge dafür, dass bei Änderung einer Eingabe das vorherige Ergebnis zurückgesetzt wird.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Controller-Seite – alle Child-Komponenten eingebettet:
<CategorySelect OnCategoryChanged="@HandleCategoryChanged" />
<ItemSelect Items="@currentItems" Disabled="@..."
            OnItemSelected="@HandleItemSelected" />
<QuantityInput OnQuantityChanged="@HandleQuantityChanged"
               Disabled="@(selectedItem == null)" />
<DualInput OnValueChanged="@HandleFeeChanged" />

<button @onclick="CalculateAsync"
        disabled="@(!canCalculate)">
    Berechnen
</button>

// Button ist deaktiviert, solange nicht alle Eingaben gültig:
private bool canCalculate =>
    selectedItem != null && quantity > 0 && fee >= 0;

// Ergebnis zurücksetzen bei neuer Eingabe:
private async Task HandleItemSelected(string item)
{
    selectedItem = item;
    result = null; // Altes Ergebnis löschen
}

// Async Calculation mit Loading-State:
private async Task CalculateAsync()
{
    isLoading = true;
    errorMessage = null;
    try
    {
        result = await someService.CalculateAsync(...);
    }
    catch (Exception ex)
    {
        errorMessage = ex.Message;
    }
    finally
    {
        isLoading = false;
    }
}

// CalculationResult.cs
public class CalculationResult
{
    public string ItemName { get; set; } = "";
    public long Quantity { get; set; }
    public decimal TotalPrice { get; set; }
    public decimal Fee { get; set; }
    public decimal NetPrice { get; set; }
    public List<Order> Orders { get; set; } = new();
}

@code {
    private string? selectedCategory;
    private string? selectedItem;
    private List<string> currentItems = new();
    private long quantity;
    private decimal fee;
    private CalculationResult? result;
    private bool isLoading;
    private string? errorMessage;

    private Dictionary<string, List<string>> data = new()
    {
        ["Ordinary"] = new() { "Veldspar", "Scordite", "Pyroxeres" },
        ["Compressed"] = new() { "Compressed Veldspar", "Compressed Scordite" },
        ["Moon"] = new() { "Bitumens", "Carnotite", "Cinnabar" },
        ["Compressed Moon"] = new() { "Compressed Bitumens", "Compressed Carnotite" },
    };

    private bool canCalculate =>
        selectedItem != null && quantity > 0 && fee >= 0;

    private async Task HandleCategoryChanged(string cat)
    {
        selectedCategory = cat;
        currentItems = data.GetValueOrDefault(cat, new());
        selectedItem = null;
        result = null;
    }

    private void HandleItemSelected(string item)
    {
        selectedItem = item;
        result = null;
    }

    private void HandleQuantityChanged(long val)
    {
        quantity = val;
        result = null;
    }

    private void HandleFeeChanged(decimal val)
    {
        fee = val;
        result = null;
    }

    private async Task CalculateAsync()
    {
        if (!canCalculate) return;

        isLoading = true;
        errorMessage = null;
        result = null;

        try
        {
            // Simulierte Berechnung (hier später echter API-Call)
            await Task.Delay(500);
            var total = quantity * 42.42m;
            var net = total * (1 - fee / 100);
            result = new CalculationResult
            {
                ItemName = selectedItem!,
                Quantity = quantity,
                TotalPrice = total,
                Fee = fee,
                NetPrice = net,
                Orders = new()
            };
        }
        catch (Exception ex)
        {
            errorMessage = ex.Message;
        }
        finally
        {
            isLoading = false;
        }
    }
}

💡 Tipps

  • Die Controller-Seite ruft StateHasChanged() nicht manuell auf (Blazor macht das automatisch bei EventCallbacks).
  • Definiere ein Datenmodell für das Ergebnis, das alle relevanten Felder bündelt.
  • Der disabled-Zustand des Berechnen-Buttons ergibt sich aus: Item != null && quantity > 0 && fee >= 0.
  • Nutze @key auf Komponenten, um Blazor bei State-Änderungen ein sauberes Re-Rendering zu ermöglichen.

✅ Akzeptanzkriterien

  • Seite enthält: Item-Auswahl, Mengen-Eingabe, Gebühren-Eingabe, Ergebnis-Tabelle
  • Alle Child-Komponenten werden per Parameter gesteuert
  • Alle Child-Änderungen werden per Callback an die Page gemeldet
  • Berechnen-Button ist deaktiviert bei ungültigen Eingaben
  • Spinner wird während der Berechnung angezeigt
  • Fehler werden als rote Meldung dargestellt
  • Bei Änderung einer Eingabe wird das vorherige Ergebnis zurückgesetzt
