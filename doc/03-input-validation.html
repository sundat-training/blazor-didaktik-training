Aufgabe 03

Input mit Validierung

🎯 Lernziel

Du erstellst ein numerisches Eingabefeld mit eigener Validierung. Du lernst, wie man Eingaben parst, Fehlerzustände verwaltet und sie benutzerfreundlich anzeigt – ohne EditForm, nur mit manuellem State.

🔧 Konzepte

<input type="number"> long.TryParse Conditional Rendering Error State EventCallback<long> [Parameter] Disabled

📋 Aufgabe

  1. 1. Erstelle die Komponente QuantityInput.razor mit einem <input type="number">.
  2. 2. Bei jeder Eingabe (@oninput) parst du den Wert mit long.TryParse(). Ist der Wert ungültig (keine Zahl, ≤ 0), setzt du einen Error-String.
  3. 3. Zeige den Error-String als rote Meldung nur an, wenn ein Fehler vorliegt (Conditional Rendering mit @if).
  4. 4. Gib den gültigen Zahlenwert per EventCallback<long> nach oben. Bei ungültiger Eingabe feuere kein Event.
  5. 5. Füge einen [Parameter] bool Disabled hinzu. Wenn true, wird das Input-Feld deaktiviert.
  6. 6. Bonus: Füge einen [Parameter] string Label und einen [Parameter] long MinValue hinzu, um die Komponente allgemein nutzbar zu machen.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// @oninput = feuert bei jedem Tastendruck:
<input type="number"
       @oninput="HandleInput"
       value="@inputValue"
       disabled="@Disabled" />

// TryParse in Blazor (e.Value ist string):
private void HandleInput(ChangeEventArgs e)
{
    var raw = e.Value?.ToString() ?? "";
    if (long.TryParse(raw, NumberStyles.Integer, CultureInfo.InvariantCulture, out var val))
    {
        // gültig
    }
    else
    {
        // Fehler setzen
    }
}

// Conditional Rendering für Fehler:
@if (!string.IsNullOrEmpty(errorMessage))
{
    <div class="text-danger">@errorMessage</div>
}

// EventCallback nur bei gültigem Wert feuern:
if (isValid)
    await OnQuantityChanged.InvokeAsync(parsedValue);

🏁 Vollständige Lösung 
@* QuantityInput.razor *@

<div class="mb-3">
    <label class="form-label fw-bold">@Label</label>
    <input type="number"
           class="form-control @(!string.IsNullOrEmpty(errorMessage) ? "is-invalid" : "")"
           @oninput="HandleInput"
           value="@inputValue"
           disabled="@Disabled"
           min="@MinValue" />
    @if (!string.IsNullOrEmpty(errorMessage))
    {
        <div class="text-danger small mt-1">@errorMessage</div>
    }
</div>

@code {
    [Parameter] public string Label { get; set; } = "Menge";
    [Parameter] public long MinValue { get; set; } = 1;
    [Parameter] public bool Disabled { get; set; }
    [Parameter] public EventCallback<long> OnQuantityChanged { get; set; }

    private string inputValue = "";
    private string? errorMessage;

    private async Task HandleInput(ChangeEventArgs e)
    {
        var raw = e.Value?.ToString() ?? "";
        inputValue = raw;

        if (string.IsNullOrWhiteSpace(raw))
        {
            errorMessage = "Feld darf nicht leer sein";
            return;
        }

        if (!long.TryParse(raw, NumberStyles.Integer,
            CultureInfo.InvariantCulture, out var val))
        {
            errorMessage = "Bitte eine gültige ganze Zahl eingeben";
            return;
        }

        if (val < MinValue)
        {
            errorMessage = $"Wert muss >= {MinValue} sein";
            return;
        }

        errorMessage = null;
        await OnQuantityChanged.InvokeAsync(val);
    }
}

💡 Tipps

  • @oninput feuert bei jedem Tastendruck, @onchange erst beim Verlassen des Feldes. Für Live-Validierung nimm @oninput.
  • Blazor parst event.args.Value als string. Du musst selbst parsen.
  • Ein leeres Feld ist auch ein Sonderfall: Soll es erlaubt sein oder ein Fehler?
  • Zusätzlich zur Textmeldung: Füge eine CSS-Klasse invalid hinzu, die das Feld rot umrandet.

✅ Akzeptanzkriterien

  • Akzeptiert nur positive ganze Zahlen > 0
  • Zeigt eine rote Fehlermeldung bei leerem Feld, 0 oder negativen Werten
  • Blockiert die Weitergabe des Wertes bei ungültiger Eingabe
  • Das Feld kann von außen deaktiviert werden
  • Das Feld hat eine rote Umrandung bei Fehler (CSS-Klasse .invalid)
