Aufgabe 04

Gekoppelte Inputs (Slider + Number)

🎯 Lernziel

Du kombinierst zwei verschiedene Input-Typen – einen <input type="range"> (Slider) und ein <input type="number"> – die denselben Wert steuern. Änderung am einen aktualisiert sofort den andere. Du lernst bidirektionale Synchronisation ohne @bind umzusetzen.

🔧 Konzepte

<input type="range"> @oninput Bidirektionale Sync Math.Round [Parameter] Min/Max/Step EventCallback<decimal>

📋 Aufgabe

  1. 1. Erstelle DualInput.razor mit einem Slider und einem Number-Input nebeneinander.
  2. 2. Beide Inputs binden an dieselbe decimal value-Variable. Änderung im Slider aktualisiert das Number-Feld und umgekehrt.
  3. 3. Verwende @oninput für den Slider (flüssige Bewegung) und @onchange für das Number-Feld (Präzisionseingabe).
  4. 4. Füge [Parameter] für Min, Max und Step hinzu, damit die Komponente flexibel bleibt.
  5. 5. Gib den Wert per EventCallback<decimal> nach oben.
  6. 6. Zeige den aktuellen Wert in Prozent-Format ("42,5 %") zwischen den beiden Inputs an.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Slider (range) mit @oninput für Echtzeit:
<input type="range"
       @oninput="HandleSliderChange"
       value="@currentValue"
       min="@Min" max="@Max" step="@Step" />

// Number-Input mit @onchange für Präzision:
<input type="number"
       @onchange="HandleNumberChange"
       value="@currentValue"
       min="@Min" max="@Max" />

// Wert-Anzeige:
<span>@currentValue.ToString("F1") %</span>

// Bidirektionale Synchronisation:
private async Task HandleSliderChange(ChangeEventArgs e)
{
    currentValue = Convert.ToDecimal(e.Value, CultureInfo.InvariantCulture);
    // Nicht erneut feuern, wenn nichts geändert
}

private async Task HandleNumberChange(ChangeEventArgs e)
{
    if (decimal.TryParse(e.Value?.ToString(), ...))
        currentValue = ...;
    await OnValueChanged.InvokeAsync(currentValue);
}

💡 Endlos-Schleifen vermeiden: Prüfe vor InvokeAsync, ob sich der Wert wirklich geändert hat.

🏁 Vollständige Lösung 
@* DualInput.razor *@

<div class="d-flex align-items-center gap-3">
    <input type="range"
           class="form-range flex-grow-1"
           @oninput="HandleSliderChange"
           value="@currentValue"
           min="@Min" max="@Max" step="@Step" />

    <span class="fw-bold text-nowrap text-center" style="min-width: 80px;">
        @currentValue.ToString("F1") %
    </span>

    <input type="number"
           class="form-control" style="width: 100px;"
           @onchange="HandleNumberChange"
           value="@currentValue"
           min="@Min" max="@Max" />
</div>

@code {
    [Parameter] public decimal Min { get; set; } = 0;
    [Parameter] public decimal Max { get; set; } = 100;
    [Parameter] public decimal Step { get; set; } = 1;
    [Parameter] public EventCallback<decimal> OnValueChanged { get; set; }

    private decimal currentValue = 0;
    private decimal previousValue = 0;

    private async Task HandleSliderChange(ChangeEventArgs e)
    {
        currentValue = Convert.ToDecimal(e.Value, CultureInfo.InvariantCulture);
        await TryFireCallback();
    }

    private async Task HandleNumberChange(ChangeEventArgs e)
    {
        var raw = e.Value?.ToString() ?? "";
        if (decimal.TryParse(raw, NumberStyles.Any,
            CultureInfo.InvariantCulture, out var val))
        {
            currentValue = Math.Round(val, 1);
            await TryFireCallback();
        }
    }

    private async Task TryFireCallback()
    {
        if (currentValue != previousValue)
        {
            previousValue = currentValue;
            await OnValueChanged.InvokeAsync(currentValue);
        }
    }
}

💡 Tipps

  • Achte auf Rundung: Der Slider liefert double, das Number-Feld decimal. Verwende Math.Round mit passender Genauigkeit.
  • Slider step sollte gröber sein (z.B. 1), das Number-Feld erlaubt beliebige Werte.
  • Vermeide Endlos-Schleifen: Wenn sich der Wert durch eine UI-Änderung nicht geändert hat, feuere kein EventCallback.
  • Setze min/max auch als HTML-Attribute, damit der Browser den Slider korrekt skaliert.

✅ Akzeptanzkriterien

  • Slider und Number-Feld zeigen immer denselben Wert an
  • Slider-Bewegung aktualisiert das Number-Feld in Echtzeit
  • Number-Eingabe aktualisiert den Slider (ggf. gerundet auf Step)
  • Min, Max und Step sind per Parameter konfigurierbar
  • Der Wert wird als formatierter String (z.B. "42,0 %") angezeigt
  • Wert-Änderungen werden per EventCallback nach oben gemeldet
