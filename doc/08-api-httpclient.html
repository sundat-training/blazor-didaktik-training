Aufgabe 08

API-Integration mit HttpClient

🎯 Lernziel

Du rufst Daten von einer externen REST-API ab und stellst sie in der UI dar. Du lernst die Einrichtung eines Typed HttpClient via IHttpClientFactory, den Umgang mit asynchronen API-Calls (async/await) und die Verarbeitung von paginierten JSON-Responses.

🔧 Konzepte

IHttpClientFactory Typed HttpClient async Task System.Text.Json Paginierung (X-Pages) Loading State / Spinner try/catch

📋 Aufgabe

  1. 1. Erstelle ein Interface IApiService und eine Implementierung ApiService.
  2. 2. Registriere den Service in Program.cs als Typed HttpClient: services.AddHttpClient<IApiService, ApiService>(c => c.BaseAddress = new Uri("https://api.example.com")).
  3. 3. Implementiere eine Methode Task<List<T>> GetDataAsync<T>(string endpoint), die:
    • Einen GET-Request an den Endpoint sendet
    • Den JSON-Response mit System.Text.Json deserialisiert
    • Den X-Pages-Header ausliest und alle Seiten abruft
    • Die Ergebnisse mit SelectMany zusammenführt
  4. 4. Füge in Program.cs einen Timeout von 30 Sekunden und einen User-Agent-Header hinzu.
  5. 5. Baue eine Komponente ApiDataView.razor mit drei Zuständen: Laden (Spinner), Daten (Tabelle), Fehler (rote Meldung).
  6. 6. Rufe die API asynchron auf: protected override async Task OnInitializedAsync() rufe await service.GetDataAsync(...).
  7. 7. Fange HttpRequestException und TaskCanceledException (Timeout) und zeige eine benutzerfreundliche Fehlermeldung.
  8. 8. Bonus: Füge einen [Parameter] int DelayMs hinzu, der zwischen Paginierungs-Requests eine Pause einlegt (Rate-Limiting).
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Typed HttpClient registrieren (Program.cs):
builder.Services.AddHttpClient<IApiService, ApiService>(client =>
{
    client.BaseAddress = new Uri("https://esi.evetech.net");
    client.Timeout = TimeSpan.FromSeconds(30);
    client.DefaultRequestHeaders.Add("User-Agent", "MyApp/1.0");
});

// GET-Request + JSON deserialisieren:
public async Task<List<T>> GetDataAsync<T>(string endpoint)
{
    var response = await httpClient.GetAsync(endpoint);
    response.EnsureSuccessStatusCode();

    var json = await response.Content.ReadAsStringAsync();
    return JsonSerializer.Deserialize<List<T>>(json, jsonOptions) ?? new();
}

// X-Pages-Header auslesen:
if (response.Headers.TryGetValues("X-Pages", out var values))
{
    totalPages = int.Parse(values.First());
}

// Paginierung mit SelectMany:
var allPages = await Task.WhenAll(
    Enumerable.Range(1, totalPages).Select(async page =>
    {
        await Task.Delay(DelayMs);
        return await GetPageAsync<T>(endpoint, page);
    })
);
return allPages.SelectMany(x => x).ToList();

    public ApiService(HttpClient httpClient)

    }

    {

        var response = await httpClient.GetAsync(endpoint + "&page=1");

            int.TryParse(values.First(), out totalPages);

    {

🏁 Vollständige Lösung 
// IApiService.cs
public interface IApiService
{
    Task<List<T>> GetDataAsync<T>(string endpoint, int delayMs = 100);
}
// ApiService.cs
public class ApiService : IApiService
{
    private readonly HttpClient httpClient;
    private readonly JsonSerializerOptions jsonOptions = new()
    {
        PropertyNameCaseInsensitive = true
    };

    public ApiService(HttpClient httpClient)
    {
        this.httpClient = httpClient;
    }

    public async Task<List<T>> GetDataAsync<T>(string endpoint, int delayMs = 100)
    {
        var firstResponse = await httpClient.GetAsync(endpoint + "&page=1");
        firstResponse.EnsureSuccessStatusCode();

        var totalPages = 1;
        if (firstResponse.Headers.TryGetValues("X-Pages", out var values))
            int.TryParse(values.First(), out totalPages);

        var firstPage = await DeserializeAsync<T>(firstResponse);
        if (totalPages <= 1) return firstPage;

        var remainingTasks = Enumerable.Range(2, totalPages - 1)
            .Select(async page =>
            {
                await Task.Delay(delayMs);
                var resp = await httpClient.GetAsync(endpoint + $"&page={page}");
                resp.EnsureSuccessStatusCode();
                return await DeserializeAsync<T>(resp);
            });

        var remainingResults = await Task.WhenAll(remainingTasks);
        return firstPage.Concat(remainingResults.SelectMany(x => x)).ToList();
    }

    private async Task<List<T>> DeserializeAsync<T>(HttpResponseMessage resp)
    {
        var json = await resp.Content.ReadAsStringAsync();
        return JsonSerializer.Deserialize<List<T>>(json, jsonOptions) ?? new();
    }
}
// Program.cs (Auszug)

    client.Timeout = TimeSpan.FromSeconds(30);
    client.DefaultRequestHeaders.Add("Accept", "application/json");
    client.DefaultRequestHeaders.Add("User-Agent", "OreCalculator/1.0");
});

💡 Tipps

  • Nutze HttpClient nicht mit new HttpClient() – immer über IHttpClientFactory (verhindert Socket-Exhaustion).
  • Der X-Pages-Header ist ein String. Parse ihn mit int.TryParse().
  • Verwende await Task.Delay(DelayMs) zwischen Paginierungs-Requests, um die API nicht zu überlasten.
  • StateHasChanged() wird nach OnInitializedAsync automatisch aufgerufen – solange du im UI-Thread bleibst.

✅ Akzeptanzkriterien

  • API-Daten werden asynchron geladen und angezeigt
  • Spinner wird während des Ladens angezeigt
  • Fehler werden abgefangen und als rote Meldung dargestellt
  • Paginierung: Alle Seiten werden abgerufen und zusammengeführt
  • HttpClient ist als Typed Client via IHttpClientFactory registriert
  • Timeout und User-Agent sind konfiguriert
