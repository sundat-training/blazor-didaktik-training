Blazor Component Training

10 aufeinander aufbauende Aufgaben, die Schritt für Schritt in die Welt der Blazor-Komponenten einführen. Jede Aufgabe ist in sich abgeschlossen und baut auf den Konzepten der vorherigen auf.

Aufgabe 01

Einfaches Select

Ein Dropdown mit festen Optionen – der Einstieg in Formularelemente und Datenbindung.

<select> @bind @onchange
Aufgabe 02

Gekaskadete Selects

Zwei abhängige Dropdowns: Die Auswahl im ersten bestimmt den Inhalt des zweiten.

<select> EventCallback Parameter
Aufgabe 03

Input mit Validierung

Ein numerisches Eingabefeld, das auf gültige Werte prüft und Fehler anzeigt.

<input> tryParse Conditional Rendering
Aufgabe 04

Gekoppelte Inputs

Slider und Zahlenfeld, die sich gegenseitig synchron halten – bidirektionale Steuerung.

<input type="range"> oninput Sync
Aufgabe 05

Einfache Tabelle

Daten aus einer Liste in einer HTML-Tabelle darstellen – der erste Schritt zu DataGrids.

<table> @foreach Conditional Rendering
Aufgabe 06

Sortierbare Tabelle

Tabellenspalten per Klick sortieren, Einträge filtern – Interaktivität in Datenansichten.

LINQ OrderBy State ▲▼
Aufgabe 07

Live-Suche / Autocomplete

Ein Textfeld, das während der Eingabe Vorschläge filtert – Echtzeit-UI mit eigenem Dropdown.

<input> oninput Positionierung
Aufgabe 08

API-Integration mit HttpClient

Daten von einer REST-API abrufen, paginieren und in der UI darstellen.

HttpClient IHttpClientFactory async/await
Aufgabe 09

Component State

Komponenten-übergreifendes State-Management mit Parametern und Callbacks.

[Parameter] EventCallback<T> Parent→Child
Aufgabe 10

CSS-Techniken & Theme

Scoped CSS, Dark/Light-Mode, responsive Layouts – das Finish für jede Komponente.

Scoped CSS ::deep Dark Mode
