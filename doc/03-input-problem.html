03

Input mit Validierung: Numerische Eingabe mit Fehleranzeige

🎯 Ziel dieser Einführung

Du baust ein Eingabefeld, das nur gültige Zahlen akzeptiert. Bei ungültiger Eingabe erscheint eine Fehlermeldung – ohne EditForm, nur mit manuellem State und Conditional Rendering.

🔍 Das Beispiel zum Ausprobieren

Gib eine Zahl ein (mindestens 1). Bei leerem Feld, Buchstaben oder Werten ≤ 0 erscheint ein Fehler.

Warte auf Eingabe...
📖 Was passiert hier?

Reines HTML + JavaScript:

// Prüft bei jeder Eingabe
input.addEventListener('input', function() {
    var raw = this.value.trim();
    var parsed = parseInt(raw, 10);

    if (raw === '' || isNaN(parsed) || parsed <= 0) {
        // Fehler anzeigen, kein Event feuern
        errorEl.textContent = 'Bitte gib eine positive ganze Zahl ein.';
        inputEl.classList.add('error');
        outputEl.textContent = '';
    } else {
        // Gültig: Fehler aus, Event feuern
        errorEl.textContent = '';
        inputEl.classList.remove('error');
        outputEl.textContent = 'Gültig: ' + parsed;
    }
});

Problem: In Blazor gibt es kein classList.add und kein direktes textContent. Du musst:

  • Den Wert mit long.TryParse() parsen
  • Einen Error-String als State-Variable führen
  • Den Error-String per @if conditional rendern
  • Eine CSS-Klasse per @if oder ternary setzen
🧩 Übertragung nach Blazor

Aus dem JS-Code wird in Blazor:

  • input.value → @bind oder @oninput an einen string rawValue
  • parseInt → long.TryParse(rawValue, out var result)
  • CSS-Klasse togglen → class="@(isError ? "error" : "")"
  • Fehlertext setzen → errorMessage = "..." (Blazor rendert automatisch)
  • EventCallback feuern → nur bei gültigem Wert

💡 Bevor du loslegst

  • Probiere die Demo: was passiert bei Buchstaben? Bei negativen Zahlen? Bei 0?
  • Überlege: Wie bildest du "CSS-Klasse togglen" in Blazor ab?
