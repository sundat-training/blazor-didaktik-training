Aufgabe 05

Einfache Tabelle

🎯 Lernziel

Du stellst eine Liste von Datenobjekten in einer HTML-Tabelle dar. Du lernst @foreach zur Iteration, bedingte Formatierung von Zeilen und den Umgang mit [Parameter]-Listen.

🔧 Konzepte

<table> <thead> / <tbody> / <tfoot> @foreach Conditional Rendering [Parameter] List<T> CSS-Klasse bedingt setzen

📋 Aufgabe

  1. 1. Erstelle ein Datenmodell Order (class / record) mit den Properties Price (decimal), Volume (long), IsBuyOrder (bool), Location (string).
  2. 2. Erstelle OrderTable.razor mit einem [Parameter] List<Order> Orders.
  3. 3. Baue eine HTML-Tabelle: <thead> mit Spaltenköpfen, <tbody> mit @foreach über die Orders.
  4. 4. Formatiere Buy-Orders mit grünem Hintergrund (class="table-success"), Sell-Orders mit rotem (class="table-danger").
  5. 5. Zeige in der Fußzeile (<tfoot>) die Gesamtanzahl der Einträge an.
  6. 6. Wenn die Liste null oder leer ist, zeige eine Meldung "Keine Daten vorhanden" statt der Tabelle.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Datenmodell (record):
public record Order(
    decimal Price,
    long Volume,
    bool IsBuyOrder,
    string Location
);

// Tabelle mit @foreach:
<table class="table table-striped">
    <thead>
        <tr>
            <th>Preis</th>
            <th>Volumen</th>
            <th>Typ</th>
            <th>Station</th>
        </tr>
    </thead>
    <tbody>
        @foreach (var order in Orders)
        {
            <tr class="@(order.IsBuyOrder ? "table-success" : "table-danger")">
                <td>@order.Price.ToString("N2")</td>
                ...
            </tr>
        }
    </tbody>
    <tfoot>
        <tr><td colspan="4">
            @Orders.Count Einträge
        </td></tr>
    </tfoot>
</table>

💡 Bedingte Anzeige mit @if (Orders?.Any() == true) – sonst "Keine Daten".

🔧 Teil-Lösung – Code-Gerüst

Ergänze die ❌-Stellen:

@* OrderTable.razor *@

<div class="card shadow">
    <div class="card-header fw-bold">@Title</div>
    <div class="card-body">
        @if (❌) // Prüfung: null oder leer
        {
            <p class="text-muted">Keine Daten vorhanden</p>
        }
        else
        {
            <div class="table-responsive">
                <table class="table table-striped table-hover mb-0">
                    <thead class="table-dark">
                        <tr>
                            <th>Preis (ISK)</th>
                            <th>Volumen</th>

                            <th>Station</th>
                        </tr>

                        {

                                ? "table-success"
                                : "table-danger")">
                                <td>@order.Price.❌</td> // Formatierung

                    </tbody>

📌 Fehlend: (1) Orders == null || Orders.Count == 0. (2) .ToString("N2") für Price-Formatierung. (3) [Parameter]-Deklarationen im @code-Block.

🏁 Vollständige Lösung 
// Order.cs (Datenmodell)
public class Order
{
    public decimal Price { get; set; }
    public long Volume { get; set; }
    public bool IsBuyOrder { get; set; }
    public string Location { get; set; } = "";
}
@* OrderTable.razor *@

<div class="card shadow">
    <div class="card-header fw-bold">@Title</div>
    <div class="card-body">
        @if (Orders == null || Orders.Count == 0)
        {
            <p class="text-muted text-center py-3">Keine Daten vorhanden</p>
        }
        else
        {
            <div class="table-responsive">
                <table class="table table-striped table-hover mb-0">
                    <thead class="table-dark">
                        <tr>
                            <th>Preis (ISK)</th>
                            <th>Volumen</th>
                            <th>Typ</th>
                            <th>Station</th>
                        </tr>
                    </thead>
                    <tbody>
                        @foreach (var order in Orders)
                        {
                            <tr class="@(order.IsBuyOrder
                                ? "table-success"
                                : "table-danger")">
                                <td class="text-end">@order.Price.ToString("N2")</td>
                                <td class="text-end">@order.Volume.ToString("N0")</td>
                                <td>@(order.IsBuyOrder ? "Ankauf" : "Verkauf")</td>
                                <td>@order.Location</td>
                            </tr>
                        }
                    </tbody>
                    <tfoot>
                        <tr class="fw-bold">
                            <td colspan="4" class="text-end">
                                @Orders.Count Eintr&auml;ge gesamt
                            </td>
                        </tr>
                    </tfoot>
                </table>
            </div>
        }
    </div>
</div>

@code {
    [Parameter]
    public string Title { get; set; } = "Marktorder";

    [Parameter]
    public List<Order>? Orders { get; set; }
}

💡 Tipps

  • Verwende string.Format("{0:N2}", item.Price) oder item.Price.ToString("N2") für formatierte Zahlen.
  • Bedingte CSS-Klasse: class="@(item.IsBuyOrder ? "table-success" : "table-danger")".
  • Gib einen [Parameter] string Title für die Card-Überschrift, damit die Komponente wiederverwendbar ist.
  • Überlege: Soll die Tabelle responsiv sein? → <div class="table-responsive"> drumherum.

✅ Akzeptanzkriterien

  • Tabelle zeigt alle übergebenen Orders mit Price, Volume, Type und Location an
  • Buy-Orders haben grünen, Sell-Orders roten Hintergrund
  • Fußzeile zeigt die Gesamtanzahl der Einträge
  • Bei leerer Liste erscheint "Keine Daten vorhanden"
  • Zahlen sind lesbar formatiert (Tausendertrennzeichen, 2 Dezimalstellen)
