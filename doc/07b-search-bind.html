Aufgabe 07b

Live-Suche / Autocomplete mit @bind

🎯 Lernziel

Du löst dieselbe Aufgabe wie in 07, aber mit @bind + @bind:event="oninput" + @bind:after. Die Filterung läuft automatisch nach jeder Bindungs-Aktualisierung – kein manueller Event-Handler nötig.

🔧 Konzepte

@bind:event="oninput" @bind:after case-insensitive Filter position: absolute Dropdown sichtbar/unsichtbar EventCallback<Item>

📋 Aufgabe

  1. 1. Erstelle SearchSelect.razor mit <input> + @bind="searchText" @bind:event="oninput" @bind:after="FilterItems".
  2. 2. Bei jeder Eingabe filtert FilterItems() die [Parameter] List<string> Items case-insensitive.
  3. 3. Zeige die Treffer als <button>-Liste im absolut positionierten Dropdown.
  4. 4. Klick auf ein Ergebnis setzt searchText und feuert EventCallback<string>.
  5. 5. Erweitere auf Objekte mit DisplayName + Value.

📌 Der Unterschied zu 07

In 07 nutzt du @oninput="HandleInput" + manuelles value. Hier übernimmt @bind das Auslesen des Input-Werts – @bind:after="FilterItems" kümmert sich um die Filterung. Kein ChangeEventArgs, kein e.Value?.ToString().

💡 Hinweise – Code-Schnipsel

Der Kern der Lösung:

// @bind + @bind:after für Live-Filter:
<input @bind="searchText"
       @bind:event="oninput"
       @bind:after="FilterItems"
       placeholder="Suchen..." />

@if (filtered.Any())
{
    <div class="dropdown">
        @foreach (var item in filtered)
        {
            <button @onclick="() => SelectItem(item)">@item</button>
        }
    </div>
}

@code {
    [Parameter] public List<string> Items { get; set; } = new();
    [Parameter] public EventCallback<string> OnItemSelected { get; set; }

    private string searchText = "";
    private List<string> filtered = new();

    private async Task FilterItems()
    {
        filtered = string.IsNullOrWhiteSpace(searchText)
            ? new()
            : Items.Where(i => i.Contains(searchText, StringComparison.OrdinalIgnoreCase))
                   .ToList();
    }

    private async Task SelectItem(string item)
    {
        searchText = item;
        filtered = new();
        await OnItemSelected.InvokeAsync(item);
    }
}

💡 @bind:after feuert nach jeder Aktualisierung von searchText – perfekt für Live-Filter.

🏁 Vollständige Lösung 
@* SearchSelect.razor *@

<div style="position:relative">
    <input type="text" class="form-control"
           @bind="searchText"
           @bind:event="oninput"
           @bind:after="FilterItems"
           placeholder="Item suchen..." />

    @if (filtered.Any())
    {
        <div class="dropdown-menu show" style="position:absolute;width:100%;z-index:1000;
             max-height:300px;overflow-y:auto">
            @foreach (var item in filtered)
            {
                <button class="dropdown-item" @onclick="() => SelectItem(item)"
                        type="button">@item</button>
            }
        </div>
    }
</div>

@code {
    [Parameter] public List<string> Items { get; set; } = new();
    [Parameter] public EventCallback<string> OnItemSelected { get; set; }

    private string searchText = "";
    private List<string> filtered = new();

    private async Task FilterItems()
    {
        filtered = string.IsNullOrWhiteSpace(searchText)
            ? new()
            : Items.Where(i => i.Contains(searchText, StringComparison.OrdinalIgnoreCase))
                   .ToList();
    }

    private async Task SelectItem(string item)
    {
        searchText = item;
        filtered = new();
        await OnItemSelected.InvokeAsync(item);
    }
}

💡 Tipps

  • @bind:event="oninput" aktualisiert bei jedem Tastendruck – nötig für Live-Suche.
  • Das Dropdown schließt sich, wenn filtered leer ist oder ein Item ausgewählt wurde.
  • Für Klick-außerhalb-schließen: umschließe Input + Dropdown mit einem @onfocusout-Container oder nutze @onblur mit setTimeout-ähnlicher Logik.

✅ Akzeptanzkriterien

  • Dropdown zeigt gefilterte Vorschläge während der Eingabe
  • Filter ist case-insensitive
  • Klick auf einen Vorschlag setzt den Input-Text und feuert Callback
  • Es wird @bind + @bind:event="oninput" + @bind:after verwendet
