Aufgabe 07

Live-Suche / Autocomplete

🎯 Lernziel

Du baust ein Textfeld, das bei jeder Tastatureingabe eine Dropdown-Liste mit passenden Vorschlägen anzeigt. Du lernst Echtzeit-Filterung (case-insensitive), das Positionieren eines absoluten Dropdowns und die Interaktion zwischen Texteingabe und Auswahl.

🔧 Konzepte

@oninput case-insensitive Filter position: absolute z-index / overflow-y Dropdown sichtbar/unsichtbar EventCallback<Item>

📋 Aufgabe

  1. 1. Erstelle SearchSelect.razor mit einem <input type="text"> und einem Dropdown-<div> darunter.
  2. 2. Bei @oninput filterst du eine [Parameter] List<string> Items case-insensitive nach dem eingegebenen Text.
  3. 3. Zeige die gefilterten Ergebnisse als Liste von <button>-Elementen im Dropdown an.
  4. 4. Positioniere das Dropdown mit position: absolute; z-index: 1000; max-height: 300px; overflow-y: auto, direkt unter dem Input.
  5. 5. Klick auf ein Ergebnis setzt den Input-Text und feuert EventCallback<string>. Das Dropdown schließt sich.
  6. 6. Das Dropdown schließt auch bei Klick außerhalb (Tipp: ein @onblur mit setTimeout-ähnlicher Logik oder ein Fokus-Container).
  7. 7. Erweitere das Datenmodell: Statt List<string> übergib eine Liste von Objekten, die sowohl DisplayName als auch Value haben.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Container mit position: relative für Dropdown-Positionierung:
<div class="position-relative">
    <input type="text" @oninput="HandleInput"
           @onblur="HandleBlur" @onfocus="HandleFocus"
           @bind:event="oninput" />

    @if (showDropdown)
    {
        <div class="position-absolute"
             style="z-index: 1000; max-height: 300px; overflow-y: auto;">
            @foreach (var item in filteredItems)
            {
                <button class="dropdown-item"
                        @onmousedown="() => SelectItem(item)">
                    @item.DisplayName
                </button>
            }
        </div>
    }
</div>

// Case-insensitive Filterung:
private void HandleInput(ChangeEventArgs e)
{
    searchText = e.Value?.ToString() ?? "";
    filteredItems = Items.Where(x =>
        x.DisplayName.Contains(searchText, StringComparison.OrdinalIgnoreCase)
        || x.Value.Contains(searchText, StringComparison.OrdinalIgnoreCase)).ToList();
    showDropdown = true;
}

// @onmousedown statt @onclick, damit @onblur nicht dazwischenfunkt:
private void SelectItem(SelectItem item)
{
    searchText = item.DisplayName;
    showDropdown = false;
    OnItemSelected.InvokeAsync(item.Value);
}

🏁 Vollständige Lösung 
// SearchItem.cs
public class SearchItem
{
    public string DisplayName { get; set; } = "";
    public string Value { get; set; } = "";
}
@* SearchSelect.razor *@

<div class="position-relative" @onfocusout="HandleFocusOut">
    <input type="text" class="form-control"
           @oninput="HandleInput"
           @onblur="HandleBlur"
           @onfocus="HandleFocus"
           value="@searchText"
           placeholder="Suche..." />

    @if (showDropdown && filteredItems.Any())
    {
        <div class="position-absolute w-100 bg-white border rounded shadow"
             style="z-index: 1000; max-height: 300px; overflow-y: auto;">
            @foreach (var item in filteredItems)
            {
                <button type="button"
                        class="d-block w-100 text-start px-3 py-2 border-0 bg-transparent"
                        @onmousedown="() => SelectItem(item)"
                        onmouseover="this.classList.add('bg-light')"
                        onmouseout="this.classList.remove('bg-light')">
                    @item.DisplayName
                    <small class="text-muted ms-2">(@item.Value)</small>
                </button>
            }
        </div>
    }

    @if (showDropdown && !filteredItems.Any() && !string.IsNullOrEmpty(searchText))
    {
        <div class="position-absolute w-100 bg-white border rounded shadow p-2 text-muted small">
            Keine Ergebnisse
        </div>
    }
</div>

@code {
    [Parameter] public List<SearchItem> Items { get; set; } = new();
    [Parameter] public EventCallback<string> OnItemSelected { get; set; }

    private string searchText = "";
    private List<SearchItem> filteredItems = new();
    private bool showDropdown = false;

    private void HandleInput(ChangeEventArgs e)
    {
        searchText = e.Value?.ToString() ?? "";
        filteredItems = Items
            .Where(x => x.DisplayName.Contains(searchText, StringComparison.OrdinalIgnoreCase)
                     || x.Value.Contains(searchText, StringComparison.OrdinalIgnoreCase))
            .ToList();
        showDropdown = true;
    }

    private void HandleBlur()
    {
        _ = Task.Run(async () =>
        {
            await Task.Delay(200);
            await InvokeAsync(() => showDropdown = false);
        });
    }

    private void HandleFocus()
    {
        if (!string.IsNullOrEmpty(searchText))
            showDropdown = true;
    }

    private void HandleFocusOut()
    {
        showDropdown = false;
    }

    private async Task SelectItem(SearchItem item)
    {
        searchText = item.DisplayName;
        showDropdown = false;
        await OnItemSelected.InvokeAsync(item.Value);
    }
}

💡 Tipps

  • Verwende StringComparison.OrdinalIgnoreCase für case-insensitive Filterung.
  • Der Dropdown-Container muss position: relative sein, damit das absolute Dropdown korrekt ausrichtet.
  • Das Schließen bei Klick außerhalb ist in Blazor knifflig. Ein Workaround: Zwei gekoppelte Events @onfocus/@onblur mit Verzögerung oder ein Container mit @onfocusout.
  • Wenn die gefilterte Liste leer ist, zeige "Keine Ergebnisse" im Dropdown an.
  • Markiere den Suchtreffer im Dropdown fett (substring + <strong>).

✅ Akzeptanzkriterien

  • Dropdown erscheint während der Eingabe unter dem Textfeld
  • Dropdown filtert case-insensitive in Echtzeit
  • Dropdown schließt bei Auswahl eines Eintrags
  • Dropdown schließt bei Klick außerhalb des Eingabebereichs
  • Auswahl setzt den Wert im Textfeld und feuert EventCallback
  • Bei leerer Trefferliste erscheint "Keine Ergebnisse"
