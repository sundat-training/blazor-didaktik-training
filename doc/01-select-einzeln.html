Aufgabe 01

Einfaches Select

🎯 Lernziel

Du erstellst eine Komponente mit einem <select>-Dropdown, das eine Liste fester Optionen anzeigt. Du lernst die verschiedenen Arten der Datenbindung in Blazor kennen: @bind für bidirektionale und @onchange für einseitige Bindung mit Aktion.

🔧 Konzepte

<select> <option> @bind @onchange foreach EventCallback<T>

📋 Aufgabe

  1. 1. Erstelle eine neue Blazor-Komponente CategorySelector.razor.
  2. 2. Definiere ein festes Array von Kategorien als Komponenten-Feld (z.B. "Ordinary", "Compressed", "Moon", "Compressed Moon").
  3. 3. Baue ein <select>, das die Kategorien als <option> ausgibt. Verwende @bind zur Bindung an eine string selectedCategory-Variable.
  4. 4. Zeige die gewählte Kategorie unterhalb des Dropdowns an.
  5. 5. Erweitere die Komponente: Gib die Auswahl per EventCallback<string> nach oben an die Parent-Komponente weiter.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine für diese Aufgabe:

// Bidirektionale Bindung (vereinfacht):
<select @bind="selectedCategory">
    <option value="" disabled>Bitte wählen...</option>
    @foreach (var cat in categories)
    {
        <option value="@cat">@cat</option>
    }
</select>

// Manuelle Steuerung mit EventCallback:
[Parameter]
public EventCallback<string> OnCategoryChanged { get; set; }

// Mit @onchange statt @bind (für Callback):
<select @onchange="HandleChange" value="@selectedCategory">
    ...
</select>

💡 @bind ist syntaktischer Zucker für value + @onchange. Sobald du @onchange selbst setzt, überschreibst du @bind.

💡 Ein EventCallback<T> wird aus der Parent-Komponente befüllt: <CategorySelector OnCategoryChanged="@HandleAuswahl" />.

🏁 Vollständige Lösung 
@* CategorySelector.razor *@

<div class="mb-3">
    <label class="form-label fw-bold">@Title</label>
    <select class="form-select" @onchange="HandleChange" value="@selectedCategory">
        <option value="" disabled selected>Bitte wählen...</option>
        @foreach (var cat in categories)
        {
            <option value="@cat">@cat</option>
        }
    </select>

    @if (!string.IsNullOrEmpty(selectedCategory))
    {
        <div class="mt-2 p-2 bg-light rounded border">
            Gewählt: <strong>@selectedCategory</strong>
        </div>
    }
</div>

@code {
    [Parameter]
    public string Title { get; set; } = "Kategorie wählen";

    [Parameter]
    public EventCallback<string> OnCategoryChanged { get; set; }

    private string selectedCategory = "";
    private string[] categories = { "Ordinary", "Compressed", "Moon", "Compressed Moon" };

    private async Task HandleChange(ChangeEventArgs e)
    {
        selectedCategory = e.Value?.ToString() ?? "";
        if (!string.IsNullOrEmpty(selectedCategory))
        {
            await OnCategoryChanged.InvokeAsync(selectedCategory);
        }
    }
}

Verwendung in einer Parent-Seite:

<CategorySelector Title="Erz-Kategorie"
                  OnCategoryChanged="@((string cat) => Console.WriteLine(cat))" />

💡 Tipps

  • Ein Platzhalter-Eintrag ("Bitte wählen...") braucht einen leeren value="" und disabled selected.
  • @bind ist syntaktischer Zucker für value + @onchange. Wenn du bei jeder Auswahl eine Aktion auslösen willst, brauchst du @onchange manuell.
  • Blazor rendert bei jeder State-Änderung neu – das ist erwünscht und kein Fehler.
  • Gib der Komponente einen [Parameter] für den Titel, damit sie wiederverwendbar wird.

✅ Akzeptanzkriterien

  • Dropdown zeigt alle Kategorien als Optionen an
  • Platzhalter "Bitte wählen..." ist vorausgewählt
  • Die gewählte Kategorie wird unterhalb des Dropdowns angezeigt
  • Die Auswahl wird per EventCallback an die Parent-Komponente gemeldet
  • Bei leerer Auswahl (Platzhalter) wird kein Event gefeuert
  • Die Komponente hat einen [Parameter] Title für die Beschriftung
