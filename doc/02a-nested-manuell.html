Aufgabe 02a

Gekaskadete Selects manuell

🎯 Lernziel

Du baust zwei <select>-Dropdowns, die voneinander abhängen: Die Auswahl im ersten Dropdown bestimmt, welche Optionen das zweite anzeigt. Du lernst, wie man EventCallback und [Parameter] nutzt, um Daten zwischen Parent- und Child-Komponenten weiterzureichen.

🔧 Konzepte

[Parameter] EventCallback<T> Parent→Child Datenfluss Dictionary<K,V> Conditional Rendering @key @onchange ChangeEventArgs

📋 Aufgabe

  1. 1. Erstelle zwei Komponenten: CategorySelect.razor (Kategorie-Auswahl) und ItemSelect.razor (Item-Auswahl).
  2. 2. CategorySelect gibt die gewählte Kategorie per EventCallback<string> nach oben.
  3. 3. ItemSelect nimmt per [Parameter] eine Liste von Items entgegen und zeigt sie im Dropdown an.
  4. 4. Erstelle eine Parent-Seite, die beide Komponenten einbettet. Bei Kategorie-Wechsel wird die Item-Liste neu gesetzt.
  5. 5. Verwende ein Dictionary<string, List<string>> als Datenquelle: Jeder Kategorie sind genau die Items zugeordnet, die in ItemSelect erscheinen.
  6. 6. Sorge dafür, dass bei Kategorie-Wechsel die Item-Auswahl zurückgesetzt wird.

📋 Beispieldaten zum Kopieren

private Dictionary<string, List<string>> data = new()
{
    ["Ordinary"] = new() { "Veldspar", "Scordite", "Pyroxeres", "Plagioclase" },
    ["Compressed"] = new() { "Compressed Veldspar", "Compressed Scordite", "Compressed Pyroxeres" },
    ["Moon"] = new() { "Bitumens", "Carnotite", "Cobaltite" },
    ["Compressed Moon"] = new() { "Compressed Bitumens", "Compressed Carnotite" },
};
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Child-Komponente empfängt Daten:
[Parameter]
public List<string> Items { get; set; }

// Parent gibt Daten weiter:
<ItemSelect Items="@currentItems" />

// Dictionary als Datenquelle:
private Dictionary<string, List<string>> data = new()
{
    ["Ordinary"] = new() { "Veldspar", "Scordite", "Pyroxeres", ... },
    ["Compressed"] = new() { "Compressed Veldspar", ... },
};

// Bei Kategorie-Wechsel:
private async Task HandleCategoryChanged(string category)
{
    currentItems = data.ContainsKey(category) ? data[category] : new();
    selectedItem = null; // Reset!
}

// @key für sauberes Re-Rendering:
<ItemSelect Items="@currentItems" @key="@selectedCategory" />
🔧 Teil-Lösung – Code-Gerüst

Parent-Seite: die "Controller"-Komponente. Ergänze die ❌-Stellen:

@* CascadingSelectPage.razor (Parent) *@

<CategorySelect OnCategoryChanged="❌" />
<ItemSelect Items="@currentItems" Disabled="@string.IsNullOrEmpty(selectedCategory)"
            OnItemSelected="HandleItemSelected" @key="@selectedCategory" />

@if (selectedItem != null)
{
    <p>Auswahl: @selectedCategory → @selectedItem</p>
}

@code {
    private string selectedCategory = "";
    private string? selectedItem;
    private List<string> currentItems = new();

    private Dictionary<string, List<string>> data = new()
    {
        ["Ordinary"] = new() { "Veldspar", "Scordite", "Pyroxeres", "Plagioclase" },
        ["Compressed"] = new() { "Compressed Veldspar", "Compressed Scordite" },
    };

    private async Task HandleCategoryChanged(string category)
    {
        selectedCategory = category;
        currentItems = data.GetValueOrDefault(category, new());
        selectedItem = null;  // Reset Item-Auswahl
    }

    private void HandleItemSelected(string item)
    {
        selectedItem = item;
        ❌ // Fehlt: Log oder Weiterleitung
    }
}

📌 Fehlend: (1) Callback-Verdrahtung in HandleCategoryChanged. (2) Beliebige Aktion in HandleItemSelected (z.B. Console.WriteLine).

🏁 Vollständige Lösung 
@* CategorySelect.razor (manuell) *@

<div class="mb-3">
    <label class="form-label fw-bold">Kategorie</label>
    <select class="form-select"
            @onchange="HandleChange"
            value="@selectedCategory">
        <option value="" disabled selected>Bitte wählen...</option>
        @foreach (var cat in categories)
        {
            <option value="@cat">@cat</option>
        }
    </select>
</div>

@code {
    [Parameter]
    public EventCallback<string> OnCategoryChanged { get; set; }

    private string selectedCategory = "";
    private string[] categories = { "Ordinary", "Compressed", "Moon", "Compressed Moon" };

    private async Task HandleChange(ChangeEventArgs e)
    {
        selectedCategory = e.Value?.ToString() ?? "";
        if (!string.IsNullOrEmpty(selectedCategory))
            await OnCategoryChanged.InvokeAsync(selectedCategory);
    }
}
@* ItemSelect.razor (manuell) *@

<div class="mb-3">
    <label class="form-label fw-bold">Item</label>
    <select class="form-select"
            @onchange="HandleChange"
            value="@selectedItem"
            disabled="@Disabled">
        <option value="" disabled selected>Bitte wählen...</option>
        @foreach (var item in Items)
        {
            <option value="@item">@item</option>
        }
    </select>
</div>

@code {
    [Parameter]
    public List<string> Items { get; set; } = new();

    [Parameter]
    public bool Disabled { get; set; }

    [Parameter]
    public EventCallback<string> OnItemSelected { get; set; }

    private string selectedItem = "";

    private async Task HandleChange(ChangeEventArgs e)
    {
        selectedItem = e.Value?.ToString() ?? "";
        if (!string.IsNullOrEmpty(selectedItem))
            await OnItemSelected.InvokeAsync(selectedItem);
    }
}

Parent-Seite: wie in Teil-Lösung, mit HandleCategoryChanged und HandleItemSelected vervollständigt.

💡 Tipps

  • Die Parent-Seite ist der "Controller": Sie hält den State und gibt ihn per Parameter an die Kinder weiter.
  • Setze ItemSelect auf disabled, solange keine Kategorie gewählt ist – das signalisiert dem Nutzer den Abhängigkeitsstatus.
  • Für das Zurücksetzen: übergib eine leere Liste oder setze den selektierten Wert auf null.
  • Verwende @key auf ItemSelect, um Blazor zu signalisieren, dass es bei Kategorie-Wechsel neu initialisieren soll.

✅ Akzeptanzkriterien

  • Kategorie-Dropdown zeigt alle Kategorien an
  • Item-Dropdown zeigt nur Items der gewählten Kategorie
  • Bei Kategorie-Wechsel wird die Item-Auswahl zurückgesetzt
  • Item-Dropdown ist deaktiviert, solange keine Kategorie gewählt ist
  • Die Auswahl beider Dropdowns wird auf der Seite angezeigt
