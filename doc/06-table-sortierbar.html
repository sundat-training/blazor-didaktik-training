Aufgabe 06

Sortierbare Tabelle mit Filter

🎯 Lernziel

Du erweiterst die Tabelle aus Aufgabe 05 um clientseitige Sortierung per Klick auf Spaltenköpfe und um einen Filter (z.B. Alle / Buy / Sell). Du lernst den Umgang mit LINQ OrderBy/ThenBy, Enums und der Sortierrichtung als Component-State.

🔧 Konzepte

LINQ OrderBy / ThenBy Enum-Filter Sortier-Status @onclick auf <th> Unicode ▲▼ IEnumerable vs List

📋 Aufgabe

  1. 1. Kopiere die Komponente aus Aufgabe 05 und erweitere sie zu SortableOrderTable.razor.
  2. 2. Definiere einen Sortier-Status: string sortColumn (z.B. "price", "volume") und bool sortAscending.
  3. 3. Mache die <th>-Elemente klickbar. Bei Klick: Wechsel der Sortierrichtung bei gleicher Spalte, sonst neue Spalte aufsteigend.
  4. 4. Zeige einen Sortier-Indikator an: " ▲" oder " ▼" neben der aktiven Spalte.
  5. 5. Implementiere eine Filter-Button-Gruppe oberhalb der Tabelle: Alle | Buy | Sell. Verwende ein Enum OrderFilter { All, Buy, Sell }.
  6. 6. Wende Filter vor der Sortierung an. Die ursprüngliche [Parameter]-Liste bleibt unverändert.
💡 Hinweise – Code-Schnipsel

Die wichtigsten Bausteine:

// Sortier-Status:
private string sortColumn = "price";
private bool sortAscending = true;

// Klickbarer Spaltenkopf:
<th @onclick="() => SortBy("price")" class="cursor-pointer">
    Preis
    @if (sortColumn == "price")
    {
        <span>@(sortAscending ? "▲" : "▼")</span>
    }
</th>

// Sortier-Logik:
private void SortBy(string column)
{
    if (sortColumn == column)
        sortAscending = !sortAscending;
    else
    {
        sortColumn = column;
        sortAscending = true;
    }
}

// LINQ-Sortierung abhängig von Spalte:
private List<Order> SortedOrders
{
    get
    {
        var filtered = Orders?.Where(o => filter == OrderFilter.All
            || (filter == OrderFilter.Buy && o.IsBuyOrder)
            || (filter == OrderFilter.Sell && !o.IsBuyOrder)) ?? new();

        return (sortColumn, sortAscending) switch
        {
            ("price", true) => filtered.OrderBy(o => o.Price).ToList(),
            ("price", false) => filtered.OrderByDescending(o => o.Price).ToList(),
            // ... volume, location, type
        };
    }
}

@code {
    [Parameter] public string Title { get; set; } = "Marktorder";
    [Parameter] public List<Order>? Orders { get; set; }

    private string sortColumn = "price";
    private bool sortAscending = true;
    private OrderFilter filter = OrderFilter.All;

    private enum OrderFilter { All, Buy, Sell }

    private string GetSortIcon(string column)
    {
        if (sortColumn != column) return "";
        return sortAscending ? "▲" : "▼";
    }

    private void SortBy(string column)
    {
        if (sortColumn == column)
            sortAscending = !sortAscending;
        else
        {
            sortColumn = column;
            sortAscending = true;
        }
    }

    private List<Order> GetProcessedOrders()
    {
        if (Orders == null) return new();

        var filtered = filter switch
        {
            OrderFilter.Buy => Orders.Where(o => o.IsBuyOrder),
            OrderFilter.Sell => Orders.Where(o => !o.IsBuyOrder),
            _ => Orders
        };

        return (sortColumn, sortAscending) switch
        {
            ("price", true) => filtered.OrderBy(o => o.Price).ToList(),
            ("price", false) => filtered.OrderByDescending(o => o.Price).ToList(),
            ("volume", true) => filtered.OrderBy(o => o.Volume).ToList(),
            ("volume", false) => filtered.OrderByDescending(o => o.Volume).ToList(),
            ("location", true) => filtered.OrderBy(o => o.Location).ToList(),
            ("location", false) => filtered.OrderByDescending(o => o.Location).ToList(),
            ("type", true) => filtered.OrderBy(o => o.IsBuyOrder).ToList(),
            ("type", false) => filtered.OrderByDescending(o => o.IsBuyOrder).ToList(),
            _ => filtered.ToList()
        };
    }

    private void SetFilter(OrderFilter f)
    {
        filter = f;
    }
}

💡 Tipps

  • Verwende switch (sortColumn) im @code-Block, um die passende Property zu sortieren.
  • Sortiere mit LINQ: Orders.Where(f).OrderBy(x => ...) und rufe .ToList() auf, damit die Sortierung nur einmal berechnet wird.
  • Der aktive Filter-Button sollte optisch hervorgehoben sein (z.B. btn-primary vs btn-outline-primary).
  • Unicode-Dreiecke: &#x25B2; (▲) und &#x25BC; (▼).

✅ Akzeptanzkriterien

  • Klick auf Spaltenkopf sortiert die Tabelle (auf-/absteigend wechselnd)
  • Aktive Sortierspalte zeigt ▲ oder ▼ an
  • Filter-Buttons (Alle/Buy/Sell) filtern die Tabelle korrekt
  • Filter und Sortierung kombinieren: erst filtern, dann sortieren
  • Die ursprüngliche Parameter-Liste wird nicht verändert
  • Bei leerem Filterergebnis erscheint eine Hinweismeldung
